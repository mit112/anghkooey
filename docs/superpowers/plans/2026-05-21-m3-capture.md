## Exit gate (from implementation plan)

- [ ] Share Extension target receives text from Safari/Books/Mail, writes to App Group inbox per ADR-0003.
- [ ] Main app drains inbox on launch and on foreground, runs `CardAuthor` (or manual entry if unavailable), presents review-and-approve sheet.
- [ ] In-app camera path: capture → OCR → `CardAuthor` (or manual) → same review sheet.
- [ ] Median share-tap → review sheet ready: <5s on iPhone 15 Pro (measured with `os_signpost`).
- [ ] App Group entitlement + bundle group ID locked and provisioned.
- [ ] Share Extension `PrivacyInfo.xcprivacy` present and audited separately from app's.

**Cut-line:** If camera OCR ships unstable, demote behind a `#if CAMERA_CAPTURE` compile flag. Share Extension ships alone; the wedge survives.

### M3.2 — InboxWriter (extension side)
**Target:** `AnghkooeyCore`  
**Owner contract:** Claude writes failing tests + `InboxWriter` protocol + skeleton  
**Implementation:** Codex  
**Files:**
- `Packages/AnghkooeyCore/Sources/AnghkooeyCore/Inbox/InboxWriter.swift`
- `Packages/AnghkooeyCore/Tests/AnghkooeyCore/InboxWriterTests.swift`

**Public API:**
```swift
public protocol InboxWriterProtocol: Sendable {
    func write(text: String, sourceApp: String) async throws
    func write(imageData: Data, sourceApp: String) async throws
}

public actor InboxWriter: InboxWriterProtocol {
    public init(containerURL: URL)   // receives App Group container URL
}
```

**Behavior contract:**
- `write(text:)`: normalizes, checks dedup (60s window + SHA-256), writes temp file, renames atomically. Returns without writing on dedup hit.
- `write(imageData:)`: writes HEIC to `images/<UUID>.heic`, then JSON item, then renames JSON atomically.
- Both: post Darwin notification after successful rename.
- Text truncation at `InboxConstants.textCharacterLimit` (last sentence boundary before limit).

**Tests (Swift Testing, no device required — use `FileManager` with a temp directory):**
```swift
@Test func textWriteCreatesFile() async throws { ... }
@Test func dedupDropsDuplicateWithin60s() async throws { ... }
@Test func dedupAllowsDuplicateAfter60s() async throws { ... }
@Test func textTruncatesAtLimit() async throws { ... }
@Test func imageRefWritesTwoFiles() async throws { ... }
@Test func atomicRenameNoPartialFileVisible() async throws { ... }   // concurrent write check
```

**Acceptance:** All `InboxWriterTests` green via `swift test`.

### M3.3 — InboxDrainer actor
**Target:** `AnghkooeyCore`  
**Owner contract:** Claude writes failing tests + protocol  
**Implementation:** Codex  
**Files:**
- `Packages/AnghkooeyCore/Sources/AnghkooeyCore/Inbox/InboxDrainer.swift`
- `Packages/AnghkooeyCore/Tests/AnghkooeyCore/InboxDrainerTests.swift`

**Public API:**
```swift
public protocol InboxDrainerDelegate: AnyObject, Sendable {
    func drainer(_ drainer: InboxDrainer, didReadItem item: InboxItem, resolvedText: String) async
    func drainer(_ drainer: InboxDrainer, didFailItem item: InboxItem, error: Error) async
}

public actor InboxDrainer {
    public init(containerURL: URL, ocr: OCRServiceProtocol, delegate: InboxDrainerDelegate)
    public func drain() async
}
```

**Behavior contract:**
- Enumerate `inbox/*.json` sorted by `capturedAt` ascending.
- Per item: decode → skip if `schemaVersion > 1` → OCR if `imageRef` → call delegate → delete on delegate success.
- Orphan eviction: delete `.json` files older than 7 days; delete `images/` files with no corresponding `.json`.
- Image size guard: skip (delete + log) images > 25 MB.
- Fault log if inbox item count > 50.
- Only one concurrent drain (actor serializes naturally).

**Tests:**
```swift
@Test func drainProcessesTextItem() async throws { ... }
@Test func drainDeletesFileAfterSuccess() async throws { ... }
@Test func drainLeavesFileOnDelegateFailure() async throws { ... }
@Test func drainEvictsOrphansOlderThan7Days() async throws { ... }
@Test func drainSkipsUnknownSchemaVersion() async throws { ... }
@Test func drainDeletesOversizeImage() async throws { ... }
@Test func concurrentDrainCallsSerialize() async throws { ... }
```

Note: `OCRServiceProtocol` already exists in `AnghkooeyIntelligence` from M2. `InboxDrainer` takes it as a dependency so tests can inject `MockOCRService`.

**Acceptance:** All `InboxDrainerTests` green via `swift test`.

### M3.4 — Darwin notification wiring
**Target:** `AnghkooeyCore`  
**Owner contract:** Claude writes skeleton + tests  
**Implementation:** Codex  
**Files:**
- `Packages/AnghkooeyCore/Sources/AnghkooeyCore/Inbox/InboxNotifier.swift`

**Public API:**
```swift
public struct InboxNotifier {
    /// Called by extension after atomic rename.
    public static func postInboxDidChange()

    /// Called by main app once on launch. Returns a cancellable token.
    public static func observeInboxDidChange(handler: @Sendable @escaping () -> Void) -> InboxNotificationToken
}

public final class InboxNotificationToken: Sendable { ... }   // cancels on deinit
```

**Behavior:** Wraps `CFNotificationCenter` Darwin API. `postInboxDidChange` posts `InboxConstants.darwinNotificationName`. `observeInboxDidChange` registers a Darwin observer and calls `handler` on the main queue; token removes the observer on deinit.

**Tests:** Darwin notifications cannot be unit-tested in the SPM sandbox (they require a running CFRunLoop with mach port access). Provide a single smoke test that verifies the notification name constant matches the ADR, and a manual test checklist item in the exit gate.

### M3.6 — Share Extension UI
**Target:** `AnghkooeyShare` extension  
**Owner:** Claude  
**Files:**
- `App/AnghkooeyShare/ShareViewController.swift`
- `App/AnghkooeyShare/AnghkooeyShare-Info.plist` (activation rules)

**Behavior:**
- `ShareViewController: UIViewController` (not `SLComposeServiceViewController` — that API is deprecated on iOS 18+).
- On `viewDidLoad`: extract `NSExtensionItem` from `extensionContext`, resolve the first `NSItemProvider` matching `public.plain-text` or `public.image`.
- For text: call `InboxWriter.write(text:sourceApp:)` then call `extensionContext?.completeRequest(returningItems: nil)`.
- For image: call `InboxWriter.write(imageData:sourceApp:)` then complete.
- Show a minimal "Saving…" / "Saved to Anghkooey" / "Error" UI (three-state). No SwiftUI — plain UIKit label + activity indicator.
- If neither text nor image available: show "Nothing to capture" and complete with `cancelRequest`.

**Acceptance:** Share from Safari → extension UI appears → JSON file appears in App Group inbox → Darwin notification fires (visible in Console.app).

## Risk register (M3-specific)

| Risk | Mitigation |
|------|-----------|
| App Group provisioning unavailable in sim | Use a local temp directory for all unit tests; provision for device testing only |
| Share Extension activation rules too narrow (misses Books highlights) | Test activation with Books + Mail + Notes in addition to Safari before exit gate |
| Darwin notification not firing in sim (CFRunLoop mode) | Verify in Console.app on device; sim may differ |
| OCR quality on handwriting / low-contrast images | Out of scope for M3. Log a warning, pass raw image-ref text as "[OCR: low confidence]" placeholder |
| Camera permission dialog blocks tests | Per learned-skill `ios-notification-permission-blocks-tests` — use MockOCRService / simulator still image path in tests; skip live camera in CI |
| `VNRecognizeTextRequest` takes >3s on complex image | Add signpost; if P95 > 3s, switch recognitionLevel from `.accurate` to `.fast` and re-measure |
